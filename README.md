# Voice

Озвучка субтитров с экрана для игр (GTA V и других): программа следит за областью с субтитрами, распознаёт текст и читает новые строки вслух. Свой голос можно задать для каждого героя («Майкл: …»).

Захват области (`xcap`) → Windows OCR → голос Windows или Piper → воспроизведение. Интерфейс на `egui`.

## Как получить exe

Скачай `Voice.exe` из вкладки **Actions** → последний запуск **Build** → Artifacts. Или собери сам: `cargo build --release` (Windows, Rust).

## Первый запуск

1. Установи русский язык с распознаванием текста: Параметры → Время и язык → Язык и регион.
2. Запусти `Voice.exe`, нажми «Выбрать мышью на экране», переключись в игру, дождись снимка и выдели область субтитров.
3. Нажми «Старт». Игра должна быть в оконном или borderless режиме.

Настройки сохраняются в `config.toml` рядом с exe.

## Голоса

- **Windows**: работает сразу, нужен русский голос в системе.
- **Piper**: нейросетевые голоса приятнее. Скачай [Piper](https://github.com/rhasspy/piper/releases) и русскую модель, укажи пути в настройках. Для многоголосых моделей в «Голосах героев» вписывай номер спикера.
