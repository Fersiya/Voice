# Voice

Озвучка субтитров с экрана для игр (например, GTA V): программа следит за областью с субтитрами, распознаёт текст и читает новые строки вслух.

Пайплайн: захват области (`xcap`) → OCR (Windows.Media.Ocr) → Piper TTS → воспроизведение (`rodio`).

## Установка

1. Rust и Windows 11.
2. Языковой пакет для OCR: Параметры → Время и язык → Язык и регион → Русский → Распознавание текста.
3. [Piper](https://github.com/rhasspy/piper/releases): распакуй в папку `piper/` рядом с проектом и положи туда русскую модель (`.onnx` и `.onnx.json`).
4. Игра в оконном или borderless режиме (в полноэкранном захват может не работать).

## Запуск

```
cargo run --release -- --shot   # снимок области в debug.png, подбери region в config.toml
cargo run --release             # озвучка
```

## Настройка

Всё в `config.toml`: область, интервал, язык OCR, путь к Piper, скорость речи и голоса по именам говорящих (формат субтитров «Имя: текст»).

## Статус

Первый каркас. Не проверен на реальной игре, координаты и фильтры OCR нужно подбирать под свой экран.
